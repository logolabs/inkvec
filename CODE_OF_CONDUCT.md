# Code of Conduct

Inkvec adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, in full, by reference. Please read it there; we have not
reproduced the text here so that a single upstream copy stays authoritative.

By participating in this project — issues, pull requests, discussions, or any other
project space — you are expected to uphold that standard.

## Reporting

To report a violation, contact the maintainers at **conduct@\<domain\>** (placeholder —
the maintainer will fill in a real address before launch). Reports are handled as
described in the Contributor Covenant's enforcement guidelines linked above.

If your report concerns a security vulnerability rather than a conduct issue, use the
process in [SECURITY.md](SECURITY.md) instead.
