# Keyboard and mouse

On a Mac, read <kbd>⌘</kbd> for <kbd>Ctrl</kbd>.

## Anywhere

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open an image |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Open the export sheet (once there is a drawing) |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |
| <kbd>F1</kbd> | This guide, at the page about what is on screen |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>8</kbd> | Choose a preset: Logo, Icon, Fine detail, Fewer paths, Photo or scan, Black & white, Line art, Editable |
| <kbd>Esc</kbd> | Close, in this order: Settings, About or the guide; the Custom wizard (keeping what you chose); the choice card (keeping Auto). With none of those open, cancel the trace in progress. |

The preset shortcuts do nothing while you are typing in a field.

## In the Vectorize viewer

| Keys or gesture | Does |
|---|---|
| Hold <kbd>Space</kbd> | Show the source instead of the SVG (A/B), until released |
| <kbd>0</kbd>, or double-click a pane | Fit the drawing to the window |
| <kbd>+</kbd> or <kbd>=</kbd> | Zoom in |
| <kbd>-</kbd> | Zoom out |
| Scroll wheel, or pinch | Zoom about the pointer |
| Drag | Pan |
| Drag the wipe divider | Move it (in Wipe) |

<kbd>Space</kbd> also flicks between Before and After in the Minify SVG tab.

## In the rail

| Keys | Does |
|---|---|
| <kbd>Tab</kbd> | Move between controls |
| Arrow keys, on a slider | Move it one step; each step traces |
| <kbd>Enter</kbd>, in a number field | Apply the value |
| <kbd>Space</kbd>, on a palette tick box | Tick or untick the ink |
| Focus a control's name | Show what it does |
| Focus an ink or a colour group | Single it out in the drawing |
| <kbd>Enter</kbd>, in the save-preset or colour field | Save or use it |
