# Keyboard and mouse

On a Mac, read <kbd>⌘</kbd> for <kbd>Ctrl</kbd>. Every drag in the viewer has a key and a single
click or tap that does the same, and every drag in the palette has a button (tick and **Merge**,
or a chip's **×**).

## Anywhere

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open an image |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Open the image on the clipboard (a screenshot, or a picture copied with *Copy image*), outside a text field |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Open the export sheet (once there is a drawing) |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |
| <kbd>F1</kbd> | This guide, at the page about what is on screen |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>9</kbd>, <kbd>Ctrl</kbd>+<kbd>0</kbd> | Choose a preset: Logo, Icon, Fine detail, Fewer paths, Photo or scan, One-colour logo, Black no background, Two-tone scan, Line art, Editable |
| <kbd>Esc</kbd> | Close, in this order: a dialog or the export sheet; Settings, About, Showcase or the guide; the Custom wizard (keeping what you chose); the choice card (keeping Auto). With none of those open, cancel the trace in progress. |

The preset shortcuts do nothing while you are typing in a field.

## In a dialog

The export sheet, Settings, About, Showcase, the guide and every dialog over the window behave
the same way:

| Keys | Does |
|---|---|
| (opening it) | The keyboard moves into it |
| <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between its controls; past the last one it goes back to the first, never to the window behind |
| <kbd>Esc</kbd> | Close it; the keyboard goes back to the button that opened it |

The window behind is out of reach while one is open, for the keyboard and for a screen reader.

## In the Vectorize viewer

| Keys or gesture | Does |
|---|---|
| Hold <kbd>Space</kbd> | Show the source instead of the SVG (A/B), until released |
| <kbd>0</kbd>, or double-click a pane | Fit the drawing to the window |
| <kbd>+</kbd> or <kbd>=</kbd> | Zoom in |
| <kbd>-</kbd> | Zoom out |
| Scroll wheel, or pinch | Zoom about the pointer |
| Drag | Pan |
| The arrow buttons beside the zoom stops | Pan a quarter of the view (shown once you have zoomed or panned) |
| <kbd>Tab</kbd> to the viewer, then the arrow keys | Pan a tenth of the view; with <kbd>Shift</kbd>, half |
| Drag the wipe divider, or tap where it should go | Move it (in Wipe) |
| <kbd>Tab</kbd> to the wipe divider, then <kbd>←</kbd> <kbd>→</kbd> | Move it 2% of the width; with <kbd>Shift</kbd>, or <kbd>Page Up</kbd> and <kbd>Page Down</kbd>, 10%; <kbd>Home</kbd> and <kbd>End</kbd> go to the ends |

<kbd>Space</kbd> also flicks between Before and After in the Minify SVG tab, whose wipe divider
works the same way.

## In the rail

| Keys | Does |
|---|---|
| <kbd>Tab</kbd> | Move between controls |
| Arrow keys, on a slider | Move it one step; each step traces |
| <kbd>Enter</kbd>, in a number field | Apply the value |
| <kbd>Space</kbd>, on a palette tick box | Tick or untick the ink |
| Focus a control's name | Show what it does |
| Focus an ink or a colour group | Single it out in the drawing |
| <kbd>Enter</kbd>, in the save-preset or colour field | Save or use it |
| <kbd>Tab</kbd> to the engine log's lines | Scroll them with the arrow keys |
