# Code of Conduct

Inkvec adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, in full, by reference. Please read it there; we have not
reproduced the text here so that a single upstream copy stays authoritative.

By participating in this project — issues, pull requests, discussions, or any other
project space — you are expected to uphold that standard.

## Reporting

To report a violation privately, use the repository's private reporting form: the
[Security tab](https://github.com/logolabs/inkvec/security), then "Report a
vulnerability", with a title that starts with **Conduct:**. The form is meant for security
reports, but it is the private channel this project has: what you write there is visible
only to you and the maintainers, and nothing is published from a conduct report. There is
no conduct mailbox.

For a comment, issue or pull request on GitHub itself, you can also use GitHub's own
"Report content" (the `...` menu on the item), which goes to GitHub rather than to us.

Reports are handled as described in the Contributor Covenant's enforcement guidelines
linked above.

If your report concerns a security vulnerability rather than a conduct issue, use the
process in [SECURITY.md](SECURITY.md) instead.
