# Results, 2026-09-15

Committed copy of the measurement tables the top-level [`README.md`](../../README.md)
quotes. The scripts write their full output under `out/`, which is gitignored (regenerate
locally with the commands below); this file holds the exact numbers cited publicly, with
their source and how to reproduce them.

## Cross-tracer comparison, 21 cases

Source: `out/crosscompare-competitors-2026-09-15/summary.md`, produced by
`bench/crosscompare_competitors.py`. 21 hash-selected cases (real brand logos, icons,
emoji), each engine's SVG scored against the source render at 1024px with CIEDE2000
(colour), SSIM, DISTS and DINOv3.

```

|---|---|---|---|---|---|---|---|---|---|---|---|
```

## Non-apples-to-apples engines, 4-way comparison

Source: `out/crosscompare-4way-2026-09-15/` (`results.json`, `manifest.json`), produced
by `bench/crosscompare_4way.py`. Same 21 cases and protocol as the table above. Adds
**covecto** (pixel-exact tracer, `--auto` and `--spline` modes) and **color-trace**
("potrace-color": pngquant quantize + potrace per layer, `-c 16 -s`), neither of which
produces artist-shaped geometry — both win raw fidelity by drawing every pixel back.

Median dE00 and median coordinate count across the 21 cases, per engine (backs
`docs/assets/results-summary.png`):

| engine | median dE00 | median coordinates |
|---|---|---|
| inkvec | 0.048 | 216 |
| vtracer-default | 0.598 | 1,266 |
| covecto (`--auto`) | 0.192 | 28,824 |
| color-trace ("potrace-color") | 0.229 | 25,018 |

Single-case detail for the `lucide/calendar-sync` icon (the hero comparison in
`docs/assets/hero-node-count.png`):

| engine | coordinates | paths | dE00 @ 1024px | seconds |
|---|---|---|---|---|
| inkvec | 216 | 1 | 0.0478 | 0.62 |
| vtracer-default | 1,610 | 4 | 0.6221 | 0.04 |
| covecto (`--auto`) | 30,090 | 50 | 0.2768 | 0.02 |
| covecto (`--spline`) | 1,610 | 4 | 0.6220 | 0.04 |
| color-trace ("potrace-color") | 36,408 | 271 | 0.2887 | 10.15 |

`covecto --spline`'s coordinates, paths and dE00 are within floating-point noise of
`vtracer-default` on every case checked — consistent with its own emitted SVGs crediting
VTracer 0.6.5 internally (see `manifest.json`'s `color_trace_source` entry and
[`docs/research/experiments-2026-09-12.md`](../research/experiments-2026-09-12.md) §10q
for the provenance note), not an independent algorithm.

Engine versions (from `manifest.json`): vtracer 0.6.15, covecto 0.1.1, color-trace via
`migvel/color_trace` (GPL-2.0-or-later, patched for Windows multiprocessing + pngquant
3.x flags), potrace 1.16, pngquant 2.17.0, DINO backbone dinov3. Protocol: original SVG
normalised to a square viewBox with 4% margin, rendered RGB on white via resvg at 512px,
scored at 1024px against the original render; clean input only.

## Damaged input: JPEG q60, restorer ablation

Source: `out/svgenius/stress_restored_n40_FIXED.log`, produced by
`bench/research/decoding/svgenius_stress_restored.py` (the corrected run — an earlier run
had a ringing-detector bug that read the wrong way; see
[`docs/research/experiments-2026-09-12.md`](../research/experiments-2026-09-12.md) for the
fix). Checkpoint in the loop for this run: `restorer_resid_flat_512mix`, step 30000 (19.92M
params) — the restorer's training lineage, not the exact checkpoint shipped today
(`restorer_widermask`, step 12000, fine-tuned from that one; see
[`release/restorer-model/README.md`](../../release/restorer-model/README.md) for the
number measured on the shipped checkpoint).

End-to-end restorer numbers (restoring before tracing, tiled inference + extreme-snap +
lenient intake, the shipped configuration) on damaged input, 144 image/format pairs across

clean input — are reported in
[`docs/research/experiments-2026-09-12.md`](../research/experiments-2026-09-12.md) §10p.D.
